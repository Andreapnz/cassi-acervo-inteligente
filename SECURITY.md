# 🔐 Política de Segurança

## Versões suportadas

| Versão | Situação |
|---|---|
| 1.0.0 | Versão atual validada |

## Proteção das informações

O CASSI – Acervo Inteligente utiliza processamento e armazenamento local de documentos técnicos.

As informações empresariais devem permanecer restritas aos ambientes autorizados.

## Informações que não devem ser publicadas

- Documentos empresariais originais.
- Bancos de dados reais.
- Dados pessoais.
- Credenciais.
- Arquivos de configuração sensíveis.
- Logs contendo informações confidenciais.
- Instaladores contendo documentos empresariais.

## Integridade

Os artefatos de distribuição devem ser submetidos à verificação SHA-256 antes da instalação.

## Dependências

As bibliotecas de terceiros devem ser avaliadas quanto à segurança, compatibilidade e licenciamento.

## Comunicação de vulnerabilidades

Possíveis vulnerabilidades devem ser comunicadas de forma privada à responsável pelo projeto.

Não devem ser publicadas evidências contendo informações empresariais ou dados sensíveis em issues públicas.

## Limitações

A execução local não substitui os controles de segurança do sistema operacional, as políticas de acesso, os backups e a proteção dos dispositivos.
