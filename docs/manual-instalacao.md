# 💻 Manual de Instalação

## 1. Requisitos recomendados

- Windows 10 ou Windows 11.
- Arquitetura x64.
- 8 GB de memória RAM.
- Aproximadamente 5 GB de espaço livre.
- Permissão administrativa, quando necessária.

## 2. Instalação

1. Obter o instalador autorizado.
2. Copiar o arquivo para o computador.
3. Verificar a integridade SHA-256.
4. Executar o instalador.
5. Seguir as instruções apresentadas.
6. Confirmar a criação do atalho, quando solicitada.
7. Aguardar a conclusão.
8. Abrir o CASSI pelo atalho.

## 3. Validação

- [ ] Instalação concluída.
- [ ] Atalho disponível.
- [ ] Interface carregada.
- [ ] Documentos disponíveis.
- [ ] Pesquisa funcionando.
- [ ] Atualização de acervos funcionando.
- [ ] Dados preservados após reinicialização.

## 4. Observações

A aplicação foi preparada para utilização sem instalação manual do ambiente de desenvolvimento.

Cada computador possui uma instalação independente.

Não desative os mecanismos de segurança do Windows para executar o instalador.

## 5. Confidencialidade

O instalador empresarial deve ser utilizado exclusivamente em computadores autorizados.
